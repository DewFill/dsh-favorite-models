# お気に入りのモデル

DeepSeek Harness の Web UI のモデル選択に星を追加し、お気に入りにしたモデルを
セレクターのルートメニューの「お気に入り」ブロックに重複して表示します。

## 使い方

1. コンポーザーのモデルメニューを開き、**Model** に進みます。
2. モデル名のすぐ後ろの星をクリックします（黄色になります）。
3. もう一度モデルメニューを開くと、**Model** と **Effort** の行の下に
   **Favourites** ブロックが現れ、お気に入りのモデルとプロバイダーが並びます。
   行をクリックするとそのモデルに切り替わり、メニューが閉じます。
4. もう一度星をクリックするとお気に入りから外れます。

モデルはプロバイダーのグループ内の元の位置に残ります。お気に入りは重複表示であり、
並べ替えではありません。

## 仕組み

プラグインは DSH の UI をコピーも置き換えもしません。標準のモデルセレクター
（`@deepseek-ai/dsh-client-ui-model-selection`）の、文書化された 2 つのスロットを
使います:

- `conversation.input.model.label` — 一覧の各行のモデル名の後ろに星を追加します
  （折りたたまれたトリガーとルートメニューの **Model** 行には星がありません）;
- `conversation.input.model.options` — ルートメニューに、他のプラグインの行と並んで
  お気に入りブロックを追加します。

お気に入りはブラウザーの `localStorage`（キー `dsh.favorite-models.v1`）に保存され、
すべてのセッションで共有されます。

## 言語

プラグインの文言とこのページは DSH の UI 言語に従います: 英語、ロシア語、中国語、
日本語、スペイン語、フランス語、ドイツ語、ポルトガル語。それ以外の言語では英語が
使われます。

## 制限

- 「お気に入り」ブロックは **Model** と **Effort** の行の後に置かれます。この
  スロットはそこにしか項目を追加できません。モデル一覧の先頭に独立したグループを
  置くには標準のセレクターを丸ごと置き換える必要があります。
- 星はモデルの行にのみ表示されます。
- お気に入りはブラウザーやデバイス間で同期されません。
