# 收藏的模型

为 DeepSeek Harness 网界面的模型选择器加上星标，并用「收藏」区块在选择器的根菜单
中重复列出已收藏的模型。

## 使用

1. 打开撰写器中的模型菜单，进入 **Model** 面板。
2. 点击模型名称后面的星标 —— 它会变成黄色。
3. 再次打开模型菜单：在 **Model** 和 **Effort** 两行下方会出现 **Favourites**
   区块，列出已收藏的模型及其服务商。点击一行即可切换到该模型并关闭菜单。
4. 再次点击星标即可取消收藏。

模型仍保留在各自的服务商分组中：收藏是重复项，不是重新排序。

## 实现方式

插件不复制、也不替换 DSH 的界面。它使用内置模型选择器
（`@deepseek-ai/dsh-client-ui-model-selection`）的两个有文档的插槽：

- `conversation.input.model.label` —— 在列表每一行的模型名称后追加星标（收起的
  触发器和根菜单的 **Model** 行没有星标）；
- `conversation.input.model.options` —— 在根菜单中、其他插件条目的旁边加入收藏
  区块。

收藏保存在浏览器的 `localStorage` 中，键名为 `dsh.favorite-models.v1`，对所有
会话共享。

## 语言

插件文案和本页面跟随 DSH 的界面语言：英语、俄语、中文、日语、西班牙语、法语、
德语和葡萄牙语。其他语言使用英语。

## 限制

- 「收藏」区块位于 **Model** 和 **Effort** 两行之后：该插槽只允许在这些位置添加
  条目。若要在模型列表最前面单独放一组，就必须整个替换内置选择器。
- 星标只出现在模型行里。
- 收藏不会在浏览器或设备之间同步。
